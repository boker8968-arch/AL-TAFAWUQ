## المرحلة 3 — تجربة التعلم

- [ ] توسيع القارئ لدعم PDF والصور والصوت والفيديو.
- [ ] تشغيل الوسائط المحلية.
- [x] أساس نظام الامتحانات وبنك الأسئلة: إدخال الامتحانات والأسئلة في حزم المحتوى وربطها بالحزم المعتمدة.
- [x] واجهة الطالب لأداء الامتحان وحفظ الإجابات والمحاولات محلياً، مع إخفاء مفاتيح الإجابة.
- [x] تصحيح آلي محدود للأسئلة ذات مفاتيح الإجابة المعتمدة، وحفظ النتيجة وجلسة الدراسة.
- [x] سجل محاولات الطالب وعرض النتائج السابقة لكل امتحان.
- [ ] مراجعة إجابات المحاولة سؤالاً بسؤال وإظهار الإجابة النموذجية بعد اعتماد مفتاحها.
- [ ] توسيع التصحيح لأنواع الأسئلة الأخرى بعد اعتماد قواعد تصحيح واضحة.

## المرحلة 4 — إدارة المحتوى والعمل دون اتصال
- [x] تصميم صيغة حزم المحتوى v1 وإضافة محلل manifest مع التحقق البنيوي من المسارات والملفات والبصمات (الاختبارات لم تُشغّل).
- [x] تنفيذ مستورد محلي يتحقق من مطابقة منهج معتمد ووجود الملفات وأحجامها وSHA-256، ويستورد الوحدات والدروس بمعاملة SQLite مع تنظيف الملفات عند فشلها.
- [x] إضافة اختبارات تكامل للمستورد: الاستيراد الناجح، SHA-256 غير المطابق، غياب اعتماد المادة، منع تكرار الحزمة، والتراجع عند فشل المعاملة (أُضيفت ولم تُشغّل بعد).
- [x] إضافة واجهة اختيار المجلد واستيراد الحزم وعرض الحزم المثبتة على Android (تحتاج اختباراً فعلياً على جهاز).
- [x] إضافة دورة مراجعة واعتماد للحزم مع سجل تدقيق؛ كل استيراد جديد يبدأ قيد المراجعة.
- [x] إضافة واجهة مراجعة تحريرية للحزم مع منع اعتماد المصدر الرسمي قبل التحقق المستقل منه.
- [ ] إضافة مصادقة وتفويض حقيقيين للمشرفين قبل أي إصدار عام.
- [ ] دعم تحديث/استبدال وحذف الحزم بطريقة آمنة.
- [ ] اختبار الاستيراد على أجهزة Android وسيناريوهات انقطاع الكهرباء أو نقص مساحة التخزين.
- [ ] النسخ الاحتياطي والاستعادة.
