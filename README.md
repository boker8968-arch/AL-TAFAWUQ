# منصة التفوق | Al-Tafawuq

تطبيق تعليمي سوداني لطلاب المرحلة الثانوية (الصفوف الأول والثاني والثالث)، مصمم للعمل دون اتصال بالإنترنت.

## الرؤية

توفير مكتبة تعليمية موثوقة وسهلة الاستخدام تضم المناهج والشروحات والملخصات والامتحانات والتدريبات، مع حفظ تقدم الطالب محلياً.

## النطاق المعتمد

- **المنصة الأولى:** Android.
- **التقنية المستهدفة:** Flutter وDart.
- **نمط التشغيل:** Offline-first؛ لا يتطلب الاستخدام التعليمي الأساسي حساباً أو خادماً.
- **التخزين المحلي:** SQLite لبيانات التطبيق والتقدم، وملفات محلية للمحتوى والوسائط.
- **اللغة والواجهة:** العربية واتجاه RTL، مع هوية خضراء زمردية وبيضاء وذهبية.
- **التكلفة:** صفر دولار؛ لا تُعتمد أي خدمة مدفوعة دون موافقة صريحة.

## الوظائف الأساسية المخطط لها

1. إعداد الطالب واختيار الصف والمسار الدراسي.
2. مكتبة المناهج والكتب.
3. الدروس والشروحات النصية والمرئية والصوتية.
4. الملخصات.
5. الامتحانات السابقة وبنك الأسئلة والتصحيح.
6. حفظ النتائج والتقدم محلياً.
7. البحث والمفضلة والجدول الدراسي.
8. استيراد حزم المحتوى وتحديثها اختيارياً.
9. النسخ الاحتياطي والاستعادة.
10. صفحات عن التطبيق والتواصل مع المطور.
